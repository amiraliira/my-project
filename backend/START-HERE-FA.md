# شروع بستهٔ مرتب‌شدهٔ rc12 — r3

راهنمای اصلی و ترتیب کار: [README.md](README.md).

هر بخش فقط یک README عملیاتی انگلیسی دارد: [بک‌اند](backend/README.md)،
[حفظ و ارتقای دیتابیس](backend/schema/README.md)، [فعال‌سازی OEE](backend/oee/README.md)،
[فرانت](frontend/README.md)، [Nginx](deploy/README.md) و [مسیر فایل‌های PM](docs/runtime-data/README.md).

بسته را در پوشهٔ جدا استخراج کنید؛ پوشهٔ قبلی، فایل تنظیمات خصوصی، دیتابیس فعلی و PMها را نگه دارید.
هدف این نسخه schema اصلی ۱۰ و OEE اختیاری ۱ است. نسخهٔ واقعی دیتابیس باید خوانده شود؛
برچسب rc10 در مرورگر نسخهٔ schema را تعیین نمی‌کند.

خطای `__version__` پیش از اتصال دیتابیس رخ می‌دهد. راه بازیابی سورس کامل و دستور بررسی
مسیر پکیج در README بک‌اند آمده است؛ فایل `__init__.py` خالی نسازید و نسخه را دستی جعل نکنید.

این بسته دادهٔ زنده، رمز واقعی یا دادهٔ پایهٔ جایگزین ندارد. اجرای دستی دستورهای سرور با شماست.
